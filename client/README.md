### Setup client
- Run `npm install`
- Run `npm run dev` to run with Vite or `npm run build` to build static files for production

### Packages/Resources used to build frontend
- lucide-vue for icons
- shadcn-vue for ready-made components
- pinia for state management
- TypeScript for typed logic, uses shared types that are located at same level as this project (shared)
- Vue for building a SPA

For more information refer to the package.json file
