### NutriPe
This repo contains both the client and server for the web-app NutriPe.

NutriPe is a app where users can create accounts, login, create recipes and create ingredients.
For more context, see the demo-video.

### Demo-video
[Here is a link](https://www.youtube.com/watch?v=jyS_hW7m4U0) to an unlisted Youtube video showing off the functionality of the app.

### Setup
For information on how to setup the project, visit the README files in client and server.

Note: shared typescript types are used and is located in the "shared" directory, it is important that the relative paths of the different folders are preserved otherwise the app might not work (obviously)
